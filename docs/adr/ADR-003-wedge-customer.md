# ADR-003: Wedge customer

- **Status:** Accepted (2026-10-10)
- **Source:** docs/plan.md §14, decision 3

## Decision
Mid-size staffing firms doing BPO and fresher hiring

## Rejected alternatives, and why
Campus first: seasonal, price-driven, slow. IT services first: needs SOC 2

## Reopen only if
2+ campus deals close before Phase 2

## Consequences for the code
Any change that contradicts this decision must be flagged in review as a blocking finding unless a superseding ADR exists.
