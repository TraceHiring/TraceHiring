# ADR-007: Candidate recourse

- **Status:** Accepted (2026-10-10)
- **Source:** docs/plan.md §14, decision 7

## Decision
Notice + 72 h response before an integrity rejection; second reviewer decides

## Rejected alternatives, and why
Appeal after decision: too late for 48-hour drives

## Reopen only if
Response rate <10% and no overturns over 6 months

## Consequences for the code
Any change that contradicts this decision must be flagged in review as a blocking finding unless a superseding ADR exists.
