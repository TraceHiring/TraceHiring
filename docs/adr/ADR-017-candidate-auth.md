# ADR-017: Candidate auth

- **Status:** Accepted (2026-10-10)
- **Source:** docs/plan.md §14, decision 17

## Decision
Invite + OTP → Trace-issued token

## Rejected alternatives, and why
Supabase Auth for candidates: limits behind shared networks, per-user billing

## Reopen only if
Not expected to reopen.

## Consequences for the code
Any change that contradicts this decision must be flagged in review as a blocking finding unless a superseding ADR exists.
