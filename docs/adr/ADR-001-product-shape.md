# ADR-001: Product shape

- **Status:** Accepted (2026-10-10)
- **Source:** docs/plan.md §14, decision 1

## Decision
Own test platform; SDK in Phase 3

## Rejected alternatives, and why
SDK only: every pilot would depend on a partner. Both at once: about 2× the work

## Reopen only if
A large platform offers distribution in exchange for an SDK

## Consequences for the code
Any change that contradicts this decision must be flagged in review as a blocking finding unless a superseding ADR exists.
