# ADR-022: Media

- **Status:** Accepted (2026-10-10)
- **Source:** docs/plan.md §14, decision 22

## Decision
Stills + flag clips, blurred on the device

## Rejected alternatives, and why
Continuous recording: privacy, bandwidth, review load

## Reopen only if
Enterprise high-stakes tier only

## Consequences for the code
Any change that contradicts this decision must be flagged in review as a blocking finding unless a superseding ADR exists.
